# 墨栈

一处整理，一处写作。

## 从这里开始

打开一个本地文件夹，左侧会列出其中的 Markdown 文档。选择文档即可编辑，分栏模式可以同时阅读排版结果。

### 写作与整理

- 文件保存在你选择的位置
- 标签页保留多个正在阅读的文档
- 大纲跳转到当前文档的标题
- 搜索框按文件名筛选工作区

> 你的文字留在本机；墨栈不需要登录或联网。

## Markdown 示例

**加粗**、*斜体*和 `行内代码` 都可以在阅读视图中呈现。

| 操作 | 快捷键 |
| --- | --- |
| 新建 | ⌘N |
| 保存 | ⌘S |
| 分栏 | ⌘2 |
